PetNext

Sistema de Gestion de mascotas en Go

Descripcion del Sistema de Gestion:
PetNext permite registrar mascotas, gestionar su alimentacion y controlar actividades de limpieza todo esto mediante archivos JSON.

Funcionalidades:
*Registrar mascotas 
*Consultar mascotas 
*Registrar alimentacion
*Registrar limpieza de arenero 
*Consultar historial 
*Persistencia de datos en JSON

Tecnologias:
*Golang
*JSON
*Git
*GitHub 
*Visual Studio Code 


Ejecucion: go run cmd/main.go
