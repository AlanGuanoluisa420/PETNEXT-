 PetNext
Sistema de Gestión de Mascotas desarrollado en Go (Golang).

Descripción
PetNext es una aplicación de consola que permite gestionar la alimentación e higiene de mascotas mediante almacenamiento persistente en archivos JSON.

Funcionalidades
Registrar mascotas
Consultar mascotas registradas
Registrar alimentación
Registrar limpieza
Consultar historial de actividades
Persistencia de datos en formato JSON
